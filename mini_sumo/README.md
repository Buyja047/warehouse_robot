# Mini Sumo — Arduino Nano + TB6612FNG

`mini_sumo.ino` — автомат мини сумо роботын код.

## Тоног төхөөрөмж

| Хэсэг | Пин |
|---|---|
| TB6612 A суваг | PWMA=D3, AIN1=D5, AIN2=D4 |
| TB6612 B суваг | PWMB=D9, BIN1=D6, BIN2=D7 |
| TB6612 STBY | D8 |
| Өрсөлдөгчийн IR (дижитал, мэдэрвэл 1) | left90=A0, left45=A5, mid=A4, right45=A3, right90=A2 |
| QTR аналог (хүрээ мэдрэх) | lLine=A7, rLine=A1 |
| Серво | D10 |
| Эхлүүлэх товч | D12 → GND (INPUT_PULLUP) |

## Хоёр чухал техникийн зүйл

1. **Servo.h ашиглаагүй.** Nano дээр `Servo` сан Timer1-ийг эзэлж, D9 ба D10-ийн
   `analogWrite`-ийг унтраадаг. PWMB нь яг D9 тул мотор B-ийн хурдны удирдлага
   алдагдана. Тиймээс сервоны импульсийг гараар (`servoPulse()`) үүсгэсэн —
   Timer1 чөлөөтэй, хоёр мотор хоёулаа бүрэн PWM-тэй.
2. **A6/A7 нь зөвхөн аналог орц.** `lLine = A7` тул `digitalRead`/`pinMode`
   ажиллахгүй. Код лайн мэдрэгчийг зөвхөн `analogRead`-аар уншина.

## Ажиллах дараалал

1. Роботыг талбайн **хар** хэсэгт тавина.
2. **D12** дарна → QTR автоматаар калибровк хийнэ (~0.4 сек, хөдөлгөхгүй).
3. Серво **90°** болно.
4. 5 секунд тоолно (`START_DELAY_MS`).
5. Тулаан эхэлнэ. Тулааны үед **D12-г дахин дарвал зогсоно**.

## Хүрээнээс гарахгүй байх логик

Талбайн хар хэсэг дээрх сарнисан цагаан толбыг үл тоохын тулд хоёр давхар шүүлт:

- **Босго**: калибровкийн үед хар талбайн дундажийг хэмжиж,
  `босго = хар_дундаж × WHITE_FACTOR` гэж тавина. Зөвхөн **тод** цагаан л давна.
- **Дараалсан баталгаа**: `LINE_CONFIRM` (анхны утга 4) удаагийн **дараалсан**
  уншилтад цагаан гарсан үед л хүрээ гэж үзнэ (≈2.8 мс ≈ 3 мм зам).
  2 см өргөн хүрээ 20 мм тул амархан баталгаажна, харин жижиг толбо шүүгдэнэ.

Хүрээ мэдрэгдмэгц: **тоормос → ухрах → эргэх → хайлт**. Энэ нь өрсөлдөгч рүү
дайрч байсан ч дээгүүр давамгайлна.

## Тохируулах гол утгууд

| Тохиргоо | Юу хийх вэ |
|---|---|
| `MOTOR_A_IS_LEFT`, `LEFT_INVERT`, `RIGHT_INVERT` | Дугуй буруу эргэвэл эхлээд эдгээрийг засна |
| `QTR_WHITE_IS_LOW` | QTR цагаан дээр их утга өгдөг бол `0` болго |
| `ENEMY_ACTIVE` | IR мэдрэгч мэдэрвэл 0 өгдөг бол `LOW` болго |
| `LINE_CONFIRM` | Толбонд хууртаж байвал ↑ (5–7), хүрээгээ алдаж байвал ↓ (2–3) |
| `WHITE_FACTOR` | ↓ болгох тусам зөвхөн илүү тод цагааныг таана |
| `BACK_MS` | Хэт их байвал АРААРАА хүрээнээс гарна. 200–260 мс орчим барь |
| `TURN_90_MS`, `TURN_180_MS` | Эргэлт дутуу/илүү бол засна |
| `START_DELAY_MS` | Тестийн үед `0` болгож болно |
| `SERVO_REFRESH_MS` | Серво ачаа барих ёстой бол `20`. Үгүй бол `0` (санал болгоно) |
| `PWM_MIN` | Бага хурдан дээр мотор эргэхгүй бол ↑ |

## Тохируулгын дараалал (санал)

1. `DEBUG_SERIAL 1` + Serial Monitor 115200 нээ.
2. Дугуй чиглэлээ шалга (`MOTOR_A_IS_LEFT` / invert).
3. Хар талбай дээр D12 дарж `CAL black L/R` ба `thr L/R` утгыг хар. Дараа нь
   хүрээн дээр гараар түлхэж `EDGE` мессеж гарч байгаа эсэхийг шалга.
4. Хар толбон дээр `EDGE` гарч байвал `LINE_CONFIRM` эсвэл `WHITE_FACTOR`-ыг засна.
5. `BACK_MS`, `TURN_90_MS`-ийг талбай дээр туршиж тохируулна.

## Анхаар

Робот дээр **ард нь лайн мэдрэгч байхгүй** тул ухрах хугацаа (`BACK_MS`) хэт урт
байвал ард талаараа хүрээнээс гарч болзошгүй. Хэрэв ард нь QTR нэмэх боломжтой
бол найдвартай байдал мэдэгдэхүйц сайжирна.
