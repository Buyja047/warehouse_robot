# Mini Sumo — Arduino Nano + TB6612FNG

`mini_sumo.ino` — автомат мини сумо робот. **Бүрэн Bluetooth удирдлагатай**:
эхлүүлэх, зогсоох, нээлтийн тактик сонгох бүгд BT-ээр. Товч байхгүй.

## Холболт

| Хэсэг | Пин |
|---|---|
| TB6612 A суваг | PWMA=D3, AIN1=D5, AIN2=D4 |
| TB6612 B суваг | PWMB=D9, BIN1=D6, BIN2=D7 |
| TB6612 STBY | D8 |
| Өрсөлдөгчийн IR (мэдэрвэл 1) | left90=A0, left45=A5, mid=A4, right45=A3, right90=A2 |
| QTR аналог (хүрээ) | lLine=A7, rLine=A1 |
| Серво | D10 |
| **Starter модуль** | **D2** (сонголтоор) |
| ~~Эхлүүлэх товч~~ | хасагдсан — **D12 сул** |
| **Bluetooth (HC-05/06)** | **D0 = RX, D1 = TX** |

> **Bluetooth залгаастай үед код АЧААЛЛАХГҮЙ.** Arduino IDE-ээс upload хийхийн
> өмнө модулийн RX/TX-ийг салга.

## Гурван техникийн анхааруулга

1. **Servo.h ашиглаагүй.** Nano дээр `Servo` сан Timer1-ийг эзэлж D9/D10-ийн
   `analogWrite`-ийг унтраадаг. PWMB = D9 тул мотор B-ийн хурд алдагдана.
   Серво импульсийг гараар үүсгэсэн (`servoGoTo()`, зөвхөн эхлэхэд).
2. **A6/A7 нь зөвхөн аналог орц.** `lLine = A7` тул `digitalRead`/`pinMode`
   ажиллахгүй — лайн мэдрэгчийг зөвхөн `analogRead`-аар уншина.
3. **Тэмдгийн конвенц**: кодын бүх газарт `1` = урагш, `-1` = ухрах, `0` = тоормос.
   Мотор урвуу холбоостой тул `LEFT_INVERT = RIGHT_INVERT = 1`. Эргүүлэлт
   `setMotors()` дотор нэг л газар хийгддэг.

## Bluetooth командууд

Ямар ч BT терминалаас нэг үсэг илгээнэ:

| Команд | Үйлдэл |
|---|---|
| `1` эсвэл `S` | **ЧИГЭЭРЭЭ** дайрах тактик |
| `2` эсвэл `L` | **ЗҮҮН** талаар тойрч дайрах |
| `3` эсвэл `R` | **БАРУУН** талаар тойрч дайрах |
| `G` | тулаан эхлүүлэх |
| `X` | зогсоох |
| `D` | QTR утга дамжуулахыг асаах/унтраах |
| `C` | **цагаан калибровк** — мэдрэгчийг цагаан хүрээн дээр тавьчихаад дар |
| `?` эсвэл `H` | төлөв ба командын жагсаалт |

Тактикаа **эхлүүлэхээс өмнө** сонгоно. Сонголт нь тэжээл унтраатал хадгалагдана.

## Нээлтийн 3 тактик

| Тактик | BT | Хөдөлгөөн |
|---|---|---|
| ЧИГЭЭРЭЭ | `1`/`S` | `OPEN_STRAIGHT_MS` турш шууд урагш давшина |
| ЗҮҮН тойролт | `2`/`L` | зүүн эргэ (`OPEN_TURN_MS`) → хажуугаар давш (`OPEN_DASH_MS`) → төв рүү эргэ (`OPEN_BACK_MS`) |
| БАРУУН тойролт | `3`/`R` | мөн адил, эсрэг талд |

Гурвуулаа **хүрээ мэдрэгдвэл эсвэл өрсөлдөгч илэрвэл** дундаас нь тасарна.

## Эхлүүлэх / зогсоох

Тулаан **хоёр замаар** эхэлнэ:

- Bluetooth `G` команд,
- starter модуль "ЯВ" болох мөчид (LOW→HIGH шилжилт).

Дараалал: **калибровк → серво 90° → 5 сек → нээлтийн тактик → хэвийн тулаан.**

Зогсох: BT `X`, эсвэл starter модуль "ЗОГС" болох.

**Зогсоох эрх нь эхлүүлсэн эзэнд байна.** Starter модуль зөвхөн ӨӨРӨӨ эхлүүлсэн
тулааныг зогсооно. Товч хасагдсан тул энэ нь заавал хэрэгтэй: эс бөгөөс модуль
"ЗОГС" барьж байхад BT `G`-ээр эхлүүлсэн тулаан тэр дороо унтарч, эхлүүлэх ямар
ч арга үлдэхгүй болно.

> Starter модуль **залгаагүй** бол `STARTER_ENABLED`-ийг `0` болго. Залгасан
> мөртлөө модулиар эхлэхгүй бол `STARTER_GO`-г `LOW` болгож үз.

⚠️ **Физик зогсоох товч байхгүй.** BT холболт тасарвал `X` хүрэхгүй. Тэмцээнд
starter модулиа заавал холбож, тулааныг модулиар эхлүүлбэл модуль нь физик
зогсоолт болно.

## Цагаан хүрээнээс гарахгүй байх

Зугтах дараалал: **тоормос → цагаанаас БҮРЭН салтал ухрах → эргэх → төв рүү явах.**

### Босго тогтоох — цагаанаа хэмжинэ

Зөвхөн хараас коэффициентээр таамаглах нь ажиллахгүй байсан: хэт хатуу бол
хүрээгээ огт танихгүй, хэт зөөлөн бол **замын бартаа/зурагдсаныг** цагаан гэж
үзээд ухарна. Бартаа нь хараас цайвар боловч жинхэнэ цагаан хүрээнээс хамаагүй
бараан — тэднийг ялгахын тулд цагаанаа хэмжих ёстой.

**Нэг удаа хийнэ:**

1. Роботоо **цагаан хүрээн дээр** тавь (хоёр QTR цагаан дээр байхаар).
2. BT-ээр **`C`** илгээ. Робот `WHITE CAL saved = ...` гэж хариулна.
3. EEPROM-д хадгалагдана — тэжээл унтраасан ч үлдэнэ, дахин хийх шаардлагагүй.

Тулаан бүрийн эхэнд хараа өөрөө дахин хэмжиж, босгыг **цагаан ба хар хоёрын
хооронд** тавина:

```
босго = цагаан + (хар − цагаан) × CAL_K        // CAL_K = 0.30
```

| Жишээ | Утга |
|---|---|
| цагаан | 200 |
| хар | 800 |
| **босго** | **380** |
| замын бартаа | ~500 → 500 > 380 тул **үл тооно** |
| жинхэнэ хүрээ | ~200 → ажиллана |

| Асуудал | Засвар |
|---|---|
| Бартааг мэдэрсээр байвал | `CAL_K` ↓ (0.30 → 0.22) |
| Хүрээгээ алдвал | `CAL_K` ↑ (0.30 → 0.45) |

Калибровк хийгээгүй бол `WHITE_FACTOR` (0.45) ашиглан зөвхөн хараас таамаглах
нөөц арга руу шилжинэ — ажиллана гэхдээ найдвар нь бага.

### Бусад хамгаалалт

1. **`LINE_CONFIRM = 9`** — 9 дараалсан цагаан уншилт (≈6.3 мс) шаардана.
   Богино бартаа шүүгдэнэ. 2 см хүрээ нь ~20 мс үргэлжлэх тул зай хангалттай.
   Бартааг мэдэрсээр байвал ↑ (11, 13), хүрээгээ алдвал ↓.
2. **Зугтах хурд ≥ дайрах хурд.** `SPD_BACK`/`SPD_ESC_TURN` нь `SPD_ATTACK`-тай
   тэнцүү. Ухралт нь түлхэлтээс удаан бол робот өөрийн импульсээрээ гарна.
3. **`reverseUntilClear()`.** Тогтмол хугацаагаар биш, хоёр QTR цэвэр хар унших
   хүртэл (`BACK_CLEAR_MS` баталгаажуулалттай) ухарна. `BACK_MAX_MS` нь ард
   талын ирмэгээс хамгаална.

### Зугтах хугацаа

Мотор тогтмол хурдтай эргэдэг (PWM удирдлага үр дүн өгөхгүй) тул зугтах
хугацааг **зөвхөн delay-ээр** зохицуулна. Одоогийн утгууд:

| Тогтмол | Өмнө | Одоо |
|---|---|---|
| `BRAKE_MS` | 60 | **20** |
| `BACK_MIN_MS` | 130 | **60** |
| `BACK_CLEAR_MS` | 90 | **35** |
| `BACK_MAX_MS` | 450 | **260** |
| `TURN_90_MS` | 360 | **180** |
| `TURN_180_MS` | 620 | **320** |
| `ESC_SETTLE_MS` | 40 | **10** |
| `ESC_FWD_MS` | 380 | **250** |

Нийт зугтах хугацаа ~1.5 сек байсныг ~0.6 сек болгов.

## Хурд

| Тогтмол | Утга |
|---|---|
| `SPEED_SCALE` | 0.60 — бүх хурдны ерөнхий коэффициент |
| `PWM_MAX` | **100** — хатуу дээд хязгаар. Хурдыг бүхэлд нь өсгөх бол ЭНИЙГ өсгө |
| `SPD_ATTACK` / `SPD_CHARGE` | 200 |
| `SPD_BACK` / `SPD_ESC_TURN` | 200 (дайралтаас бага байж болохгүй) |
| `SPD_CURVE` / `SPD_SPIN` / `SPD_SEARCH` | 150 / 140 / 135 |
| `PWM_MIN` | 55 — үүнээс доош мотор эргэхгүй |

`PWM_MAX = 100` тул 167-оос дээш бүх утга ижил үр дүн өгнө
(`200 × 0.60 = 120 → 100`).

## Тохируулгын дараалал

1. BT терминал холбож `?` дарж холболтоо шалга.
2. **Цагаан калибровк хий** — роботоо цагаан хүрээн дээр тавиад `C` илгээ. Нэг л удаа.
3. `D` дарж QTR утгыг хар. Роботоо бартаа ба жинхэнэ хүрээ дээгүүр удаанаар
   өнгөрүүлж, `thr` нь тэр хоёрын хооронд байгаа эсэхийг шалга.
   Бартааг мэдэрвэл `CAL_K` ↓, хүрээгээ алдвал `CAL_K` ↑.
4. **Зугтах хугацааг тааруул** (хурд өөрчлөгддөггүй тул цорын ганц хөшүүрэг):
   `BACK_MAX_MS`, `TURN_90_MS`, `TURN_180_MS`, `ESC_FWD_MS`.
   Эргэлт дутуу бол `TURN_*_MS` ↑, хэтэрвэл ↓. Хүрээнээс салахгүй бол
   `BACK_MIN_MS` / `BACK_MAX_MS` ↑.
5. Нээлтийн тактикуудыг `OPEN_TURN_MS` / `OPEN_DASH_MS` / `OPEN_BACK_MS`-ээр тааруул.

## Анхаар

Ард нь лайн мэдрэгч байхгүй тул `BACK_MAX_MS` хэт урт байвал ард талаараа
хүрээнээс гарч болзошгүй. Ард нь QTR нэмбэл найдвартай байдал мэдэгдэхүйц
сайжирна.
