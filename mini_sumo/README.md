# Mini Sumo — Arduino Nano + TB6612FNG

`mini_sumo.ino` — автомат мини сумо роботын код (state machine + хурдны удирдлага).

## Тоног төхөөрөмж

| Хэсэг | Пин |
|---|---|
| TB6612 A суваг | PWMA=D3, AIN1=D5, AIN2=D4 |
| TB6612 B суваг | PWMB=D9, BIN1=D6, BIN2=D7 |
| TB6612 STBY | D8 |
| Өрсөлдөгчийн IR (дижитал, мэдэрвэл 1) | left90=A0, left45=A5, mid=A4, right45=A3, right90=A2 |
| QTR аналог (хүрээ мэдрэх) | lLine=A7, rLine=A1 |
| Серво | D10 |
| Эхлүүлэх товч | D12 → GND (INPUT_PULLUP) |

## Хоёр чухал техникийн зүйл

1. **Servo.h ашиглаагүй.** Nano дээр `Servo` сан Timer1-ийг эзэлж, D9/D10-ийн
   `analogWrite`-ийг унтраадаг. PWMB нь яг D9 тул мотор B-ийн хурдны удирдлага
   алдагдана. Сервоны импульсийг гараар үүсгэсэн (`servoGoTo()`, зөвхөн эхлэхэд).
2. **A6/A7 нь зөвхөн аналог орц.** `lLine = A7` тул `digitalRead`/`pinMode`
   ажиллахгүй — лайн мэдрэгчийг зөвхөн `analogRead`-аар уншина.

## Тэмдгийн конвенц

Кодын **бүх** газарт: `1` = урагш, `-1` = ухрах, `0` = тоормос.

Энэ роботын мотор урвуу холбоостой (AIN1=LOW/AIN2=HIGH үед урагш явдаг) тул
`LEFT_INVERT = 1`, `RIGHT_INVERT = 1`. Тэмдгийн эргүүлэлт `setMotors()` дотор
нэг л газар хийгддэг — логик хэсэгт хаана ч тэмдэг эргүүлэх хэрэггүй.

Нэг дугуй нь эсрэг эргэвэл **зөвхөн тэр талынх** нь invert-ийг `0` болго.

## Хурдны удирдлага

Чиглэлийг `AIN1/AIN2`, `BIN1/BIN2` пин зааж, хурдыг `PWMA/PWMB` дээрх
`analogWrite`-аар өгнө (өмнө нь PWM пинийг байнга HIGH байлгаж 100% хурдаар
явдаг байсан).

| Тогтмол | Утга | ~% | Хаана |
|---|---|---|---|
| `SPD_CHARGE` | 110 | 43% | эхний сохор дайралт |
| `SPD_ATTACK` | 120 | 47% | `mid` дээр түлхэх |
| `SPD_CURVE` | 100 | 39% | 45° хурц нум |
| `SPD_SPIN` | 95 | 37% | 90° байрандаа эргэх |
| `SPD_SEARCH` | 90 | 35% | өрсөлдөгчийг алдсан үеийн хайлт |
| `SPD_BACK` | 105 | 41% | хүрээнээс ухрах |
| `SPD_ESC_TURN` | 110 | 43% | хүрээнээс зайлж эргэх |
| `PWM_MIN` | 55 | — | үүнээс доош мотор огт эргэхгүй (үхмэл бүс) |

**`SPEED_SCALE`** — бүх хурдыг нэг дор мушгих гол тохируулга. `1.00` = дээрх
утгууд хэвээр, `0.70` = 30% удаан, `1.20` = 20% хурдан.

### PWM ажиллаж байгаа эсэхийг шалгах

Хурд буухгүй байвал `TEST_SPEED_MODE`-ийг `1` болгож ачаал. Товч дархад тулаан
эхлэхгүй, оронд нь мотор 5 шатаар (60 → 100 → 150 → 200 → 255) тус бүр 2.5 сек
эргэнэ. **Роботыг өргөж барь** — дугуй чөлөөтэй эргэх ёстой.

- Шат бүрт хурд өөр байвал → PWM зөв, `SPEED_SCALE`-ээр тааруул.
- Бүх шат ижил хурдтай байвал → PWMA/PWMB утас драйверт хүрэхгүй байна, эсвэл
  драйвер дээрх PWM пин VCC рүү холбоостой (техник хангамжийн асуудал).
- Эхний 1–2 шат огт эргэхгүй бол → `PWM_MIN`-ийг өсгө.

> **Хурдыг өөрчилсөн бол эргэлтийн хугацааг ЗААВАЛ дахин тааруул.** Хурд буурвал
> ижил өнцгийг эргэхэд илүү удаан хугацаа шаардана — `TURN_90_MS`,
> `TURN_180_MS`, `BACK_MS` гурвыг талбай дээр туршиж засна.

## Ажиллах дараалал

1. Роботыг талбайн **хар** хэсэгт тавина.
2. **D12** дарна → QTR автоматаар калибровк хийнэ (~0.4 сек, хөдөлгөхгүй).
3. Серво **90°** болно.
4. 5 секунд тоолно (`START_DELAY_MS`).
5. Эхний `FIRST_CHARGE_MS` (1.5 сек) чигээрээ сохроор дайрна.
6. Дараа нь мэдрэгчийн төлвөөр хайж түлхэнэ.

Тулааны үед **D12-г дахин дарвал зогсоно**. Хүрээ мэдрэгдвэл сохор дайралт
шууд цуцлагдана.

## Хүрээнээс гарахгүй байх логик

Хар хэсэг дээрх сарнисан цагаан толбыг үл тоохын тулд хоёр давхар шүүлт:

- **Авто калибровк** — хар талбайн дундажийг хэмжиж
  `босго = хар_дундаж × WHITE_FACTOR` (0.30). Зөвхөн маш тод цагаан л давна.
- **Дараалсан баталгаа** — `LINE_CONFIRM` (7) удаагийн **дараалсан** уншилтад
  цагаан гарсан үед л хүрээ гэж үзнэ (≈4.9 мс). 2 см өргөн хүрээ амархан
  баталгаажна, богино толбо шүүгдэнэ.

Хүрээ мэдрэгдмэгц: **тоормос → ухрах → эргэх → хайлт**. Энэ нь дайралтаас
дээгүүр давамгайлна.

## Тохируулах гол утгууд

| Тохиргоо | Юу хийх вэ |
|---|---|
| `LEFT_INVERT`, `RIGHT_INVERT` | Дугуй буруу эргэвэл эхлээд эдгээрийг засна |
| `SPEED_SCALE` | Бүх хурдыг нэг дор нэмэх/хасах |
| `ENEMY_ACTIVE` | IR мэдрэгч мэдэрвэл 0 өгдөг бол `LOW` болго |
| `LINE_CONFIRM` | Толбонд хууртаж байвал ↑, хүрээгээ алдаж байвал ↓ |
| `WHITE_FACTOR` | ↓ болгох тусам зөвхөн илүү тод цагааныг таана |
| `BACK_MS` | Хэт их байвал **араараа** хүрээнээс гарна |
| `TURN_90_MS`, `TURN_180_MS` | Эргэлт дутуу/илүү бол засна |
| `FIRST_CHARGE_MS` | Эхний сохор дайралтын хугацаа. `0` = унтраах |
| `START_DELAY_MS` | Тестийн үед `0` болгож болно |
| `PWM_MIN` | Бага хурдан дээр мотор эргэхгүй бол ↑ |

## Анхаар

Робот дээр **ард нь лайн мэдрэгч байхгүй** тул `BACK_MS` хэт урт байвал ард
талаараа хүрээнээс гарч болзошгүй. Ард нь QTR нэмбэл найдвартай байдал
мэдэгдэхүйц сайжирна.
