# Mini Sumo — ESP32 + Bluepad32 (сайжруулсан хувилбар)

`mini_sumo/mini_sumo.ino` нь хуучин кодыг эхнээс нь дахин бичсэн хувилбар.
**GPIO пин нэг ч өөрчлөгдөөгүй**, sensor board-ын UART протокол, LED, товч,
тэжээлийн (POWER_PIN) логик хэвээрээ. Зөвхөн **удирдлагын хэсэг** сайжирсан.

Сан суулгах: [Arduino Core for ESP32 + Bluepad32 (Option A)](https://bluepad32.readthedocs.io/en/latest/plat_arduino/)

---

## 1. Start модуль (GPIO15) = kill switch

| Дохио | Үйлдэл |
|---|---|
| LOW → HIGH (RISING) | Эхлэх (5 сек хүлээгээд стратеги ажиллана) |
| HIGH → LOW (FALLING) | **Шууд зогсоод IDLE** — ramp хүлээхгүй, тоормос шууд |

- Дохио нэг ч удаа жинхэнэ шилжилт хийсэн бол `startModulePresent` тогтож,
  **зогсоох/эхлүүлэх эрхийг бүхэлд нь Start модуль эзэмшинэ** — товч болон
  gamepad-аар эхлүүлэх боломжгүй болно (робот хөдөлж байхад товч дарах
  боломжгүй тул). Товч зөвхөн стратеги солих, зогсоох, тэжээл унтраахад
  үлдэнэ.
- Асаах агшинд дохио аль хэдийн HIGH байсан бол **робот эхлэхгүй** — заавал
  жинхэнэ LOW→HIGH шилжилт хэрэгтэй (санамсаргүй хөдлөхөөс хамгаална).
- Хариу үйлдэл: зогсох 3 мс, эхлэх 15 мс (debounce).

### Оролтын горим
Анхдагчаар `INPUT_PULLDOWN` — кабель салсан/модуль унтарсан үед оролт LOW
болж робот ЗОГССОН төлөв рүү унана (fail-safe).

```c
#define START_PIN_MODE   INPUT_PULLDOWN  // open-collector модуль бол INPUT_PULLUP
#define START_ACTIVE_HIGH 1              // модуль урвуу бол 0
#define START_COUNTDOWN_MS 5000          // дүрмийн 5 сек; хэрэггүй бол 0
```

Start модулийг холбоогүй үед (пин LOW хэвээр) робот "модуль байхгүй" гэж үзэж,
BUTTON2-ыг удаан дарах / gamepad R1-ээр эхлүүлэх боломжтой — тэвшин дээрх тест
ажиллана.

## 2. Гараар удирдах (manual) — хоцрогдолгүй

Хуучин кодын хоцрогдлын шалтгаанууд болон засвар:

| Асуудал | Засвар |
|---|---|
| `manualMode()` дотор 1 мс тутам `Serial.printf` → 115200 baud дүүрч loop блоклоно | Тулааны үед хэвлэхгүй; телеметр зөвхөн IDLE үед 5 Гц |
| `BP32.update()` 10 мс тутам | `loop()` бүрт дуудна, утга кэшлэгдэнэ |
| `usart_check()` нэг loop-д 1 байт → frame алдана | Буферийг бүрэн уншина (`setRxBufferSize(512)`) |
| Контроллер салахад `myController` NULL руу хандаж reset болно | `padConnected` шалгалт + салмагц мотор зогсоно |
| Stick drift | ±40 deadzone |
| Ramp удаан | Manual accel 30 / decel 45 (0→100% ≈ 4 мс) |

Хэмжсэн үр дүн (host симуляц): **0 → 100% — 4 мс, зогсох — 3 мс.**

Удирдлага (хуучинтай ижил): зүүн/баруун stick = зүүн/баруун мотор,
R1 = хурд ихсгэх, R2/L2 = байрандаа эргэх, L1 = бүрэн урагш,
□ 200мс дарах = AUTO ↔ MANUAL.

## 3. Automat — цагаан зураас давахгүй

Талбай: **дугуй хар талбай + 2 см цагаан хүрээ**, хар талбай дээр бага зэрэг
цагаан маажилт/зураас байдаг.

### a) Автомат калибровк
IDLE үед (робот хар талбай дээр зогсож байхад) хоёр line сенсорын "хар"
суурь утга (`blackRef`) EMA-аар тогтмол шинэчлэгдэнэ. Босгууд нь тогтмол тоо
биш, **суурийн хувиар** тодорхойлогдоно:

```
strong босго = blackRef * 45%     (тод цагаан)
weak   босго = blackRef * 70%     (сул цагаан)
```

Тиймээс гэрэлтүүлэг, талбайн өнгө өөр байсан ч дахин тохируулах шаардлагагүй.

### b) Маажилт vs жинхэнэ хүрээ — ХУГАЦААГААР ялгана

| Нөхцөл | Шийдэл |
|---|---|
| Тод цагаан ≥ 2 мс | Ирмэг → зугтана |
| Сул цагаан ≥ 7 мс | Ирмэг → зугтана |
| Үүнээс богино | **Маажилт гэж үзэж үл тоомсорлоно** |

1 м/с хурдтай явахад 2 мс = 2 мм зам. 2 см-ийн хүрээ = 20 мм тул найдвартай
барина, харин нимгэн зураас (< 2 мм) огт мэдрэгдэхгүй. Симуляцаар шалгасан:
1 мс-ийн тод маажилт болон 4 мс-ийн сул тэмдэглэгээ **огт триггер болоогүй**,
жинхэнэ зураас **3 мс-т** мэдрэгдсэн.

### c) Зугтах маневр (ямар ч төлөвөөс дээгүүр эрхтэй)
```
ирмэг → ШУУД тоормос (ramp алгасна) → 190 мс ухрах → 165 мс дотогш эргэх → хайлт
```
- Хоёр сенсор зэрэг ажиллавал илүү удаан ухраад 2 дахин эргэнэ.
- Эргэж байхад дахин ирмэг олдвол дахин ухарна (`EDGE_RETRY_MAX` хүртэл).
- Нээлтийн стратеги, довтолгоо, хайлт — бүгд ирмэгээр таслагдана.

### d) Нэмэлт хамгаалалт
- **Sensor board timeout**: 200 мс frame ирэхгүй бол робот сохроор гүйхгүй,
  автоматаар зогсоод LED улаанаар анивчина (`REQUIRE_SENSOR_BOARD`).
- Checksum алдаатай frame-ийг хаяж, 0x55-аар дахин sync хийнэ.

### e) Довтолгоо
6 мэдрэгчийн bit-үүдээс өрсөлдөгчийн байрлалыг жигнэсэн дунджаар тооцно
(хуучин `switch`-ийн 64 хувилбарын нүхийг арилгав):

| Байрлал | Үйлдэл |
|---|---|
| Урд | 100% шулуун түлхэлт |
| 45° | Нумаар дайрах (гадна 100 / дотор 20) |
| 90° | Байрандаа 95%-иар эргэх |
| Байхгүй | Хайлт: эргэх ↔ богино урагшлалт солигдоно, сүүлд харсан тал руу |

## 4. Товчны удирдлага

| Үйлдэл | Утга |
|---|---|
| BUTTON2 нэг товшилт | Дараагийн стратеги (LED өнгө) |
| BUTTON2 давхар товшилт | Өмнөх стратеги |
| BUTTON2 удаан дарах | Эхлэх/зогсох (**зөвхөн Start модуль холбоогүй үед эхэлнэ**) |
| BUTTON2 гурван товшилт | Тэжээл унтраах |
| BUTTON1 200 мс | Зогсох |
| BUTTON1 500 мс | Тэжээл унтраах |
| Асаахад BUTTON2 + BUTTON1 | Bluetooth түлхүүр устгах (дахин pairing) |

`BP32.forgetBluetoothKeys()` бүр асаах бүрт дуудагдахаа больсон тул gamepad
хурдан бөгөөд найдвартай дахин холбогдоно.

## LED утга

| LED | Утга |
|---|---|
| 0 | Сонгосон стратеги (ногоон/цэнхэр/улаан/шар/ягаан/цайвар цэнхэр) |
| 1 | Төлөв: сул цагаан = IDLE, сул улаан = Start модуль зогсоосон, шар анивчилт = 5 сек тоолол, ногоон = тулаан, улаан = ирмэгээс зугтаж байна, улаан анивчилт = sensor board холбоогүй |
| 2 | Ногоон = AUTO, цэнхэр = MANUAL |

## 5. Тохируулах гол параметрүүд

```c
// Ирмэг мэдрэх мэдрэмж
#define LINE_STRONG_PCT 45   // багасгах = мэдрэмж буурна (маажилтад тэсвэртэй)
#define LINE_WEAK_PCT   70
#define LINE_STRONG_MS  2    // ихэсгэх = маажилтад тэсвэртэй, гэхдээ хариу удаан
#define LINE_WEAK_MS    7

// Зугтах маневр
#define EDGE_BACK_MS   190   // хэт их бол ард талаараа гарах эрсдэлтэй
#define EDGE_TURN_MS   165   // 90° орчим эргэхээр тохируул

// Хурд
#define ATTACK_SPEED   100
#define SEARCH_TURN     72
```

**Эхний тохируулга:** роботыг хар талбай дээр 1-2 секунд зогсоо (blackRef
калибровк хийгдэнэ) → Serial Monitor (115200) дээр `refL/refR` болон `L/R`
утгуудыг хараад цагаан хүрээ дээр тавихад утга босгоос доош унаж байгааг
шалга.

> Хэрэв таны борд **цагаан = ӨНДӨР** утга өгдөг бол `LINE_WHITE_IS_LOW` -ийг
> `0` болго (одоогийн код хуучин кодтой ижил — цагаан = БАГА утга).

## 6. Шалгасан байдал

Host дээр Arduino-ийн stub санг ашиглан симуляц ажиллуулж, 30 шалгалт бүгд
давсан: калибровк, Start модулийн RISING/FALLING, маажилт үл тоомсорлох,
жинхэнэ зураасны 3 мс хариу, зугтах дараалал, довтолгооны чиглэл, sensor
board тасрах, manual-ийн 4 мс хариу, kill switch manual дээр үйлчлэх.

Мөн ESP32 Arduino core **2.x болон 3.x** хоёуланд компайл болохоор LEDC/timer
API-г боож өгсөн.
