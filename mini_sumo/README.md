# Mini Sumo — Arduino Nano + TB6612FNG

`mini_sumo.ino` — автомат мини сумо робот: 3 нээлтийн тактик, Bluetooth удирдлага,
starter модуль, цагаан хүрээнээс зайлах логик.

## Холболт

| Хэсэг | Пин |
|---|---|
| TB6612 A суваг | PWMA=D3, AIN1=D5, AIN2=D4 |
| TB6612 B суваг | PWMB=D9, BIN1=D6, BIN2=D7 |
| TB6612 STBY | D8 |
| Өрсөлдөгчийн IR (мэдэрвэл 1) | left90=A0, left45=A5, mid=A4, right45=A3, right90=A2 |
| QTR аналог (хүрээ) | lLine=A7, rLine=A1 |
| Серво | D10 |
| Эхлүүлэх товч | D12 → GND (INPUT_PULLUP) |
| **Starter модуль** | **D2** |
| **Bluetooth (HC-05/06)** | **D0 = RX, D1 = TX** |

> **Bluetooth залгаастай үед код АЧААЛЛАХГҮЙ.** Arduino IDE-ээс upload хийхийн
> өмнө модулийн RX/TX-ийг салга.

## Гурван техникийн анхааруулга

1. **Servo.h ашиглаагүй.** Nano дээр `Servo` сан Timer1-ийг эзэлж D9/D10-ийн
   `analogWrite`-ийг унтраадаг. PWMB = D9 тул мотор B-ийн хурд алдагдана.
   Серво импульсийг гараар үүсгэсэн (`servoGoTo()`, зөвхөн эхлэхэд).
2. **A6/A7 нь зөвхөн аналог орц.** `lLine = A7` тул `digitalRead`/`pinMode`
   ажиллахгүй — лайн мэдрэгчийг зөвхөн `analogRead`-аар уншина.
3. **Тэмдгийн конвенц**: кодын бүх газарт `1` = урагш, `-1` = ухрах, `0` = тоормос.
   Мотор урвуу холбоостой тул `LEFT_INVERT = RIGHT_INVERT = 1`. Эргүүлэлт
   `setMotors()` дотор нэг л газар хийгддэг.

## Bluetooth командууд

Ямар ч BT терминалаас нэг үсэг илгээнэ:

| Команд | Үйлдэл |
|---|---|
| `1` эсвэл `L` | ЗҮҮН талаар дайрах тактик |
| `2` эсвэл `S` | ЧИГЭЭРЭЭ дайрах тактик |
| `3` эсвэл `R` | БАРУУН талаар дайрах тактик |
| `G` | тулаан эхлүүлэх |
| `X` | яаралтай зогсоох |
| `D` | QTR утга дамжуулахыг асаах/унтраах |
| `C` | **цагааны калибровк** (нэг удаа, EEPROM-д хадгална) |
| `?` | одоогийн төлөв харах |

## Нээлтийн 3 тактик

| Тактик | Хөдөлгөөн |
|---|---|
| ЧИГЭЭРЭЭ | `OPEN_STRAIGHT_MS` турш шууд урагш давшина |
| ЗҮҮН | зүүн эргэ (`OPEN_TURN_MS`) → хажуугаар давш (`OPEN_DASH_MS`) → төв рүү эргэ (`OPEN_BACK_MS`) |
| БАРУУН | мөн адил, эсрэг талд |

Гурвуулаа **хүрээ мэдрэгдвэл эсвэл өрсөлдөгч илэрвэл** дундаас нь тасарна.

## Эхлүүлэх / зогсоох

Тулаан **гурван замаар** эхэлнэ:

- starter модуль "ЯВ" болох мөчид (LOW→HIGH шилжилт),
- Bluetooth `G` команд,
- D12 товч.

Дараалал: **калибровк → серво 90° → 5 сек → нээлтийн тактик → хэвийн тулаан.**

Зогсох: starter модуль "ЗОГС" болох, BT `X`, эсвэл D12 дарах.

**Зогсоох эрх нь эхлүүлсэн эзэнд байна.** Starter модуль зөвхөн ӨӨРӨӨ эхлүүлсэн
тулааныг зогсооно. Тиймээс модуль "ЗОГС" барьж байсан ч D12 товч / BT `G`-ээр
эхлүүлсэн тест хэвийн үргэлжилнэ — ширээн дээр туршихад модулиа салгах
шаардлагагүй.

> Starter модуль **залгаагүй** бол `STARTER_ENABLED`-ийг `0` болгож болно
> (D2 нь INPUT_PULLUP тул залгаагүй ч товч ажиллана). Залгасан мөртлөө
> модулиар эхлэхгүй бол `STARTER_GO`-г `LOW` болгож үз.

## Цагаан хүрээнээс гарахгүй байх

Зугтах дараалал: **тоормос → цагаанаас БҮРЭН салтал ухрах → эргэх → төв рүү явах.**

### Хоёр цэгийн калибровк (гол хэсэг)

Зөвхөн хараас коэффициентээр босго таамаглах нь ажиллахгүй: хэт хатуу бол
хүрээгээ огт танихгүй, хэт зөөлөн бол **талбайн зурагдсан/элэгдсэн хэсгийг**
цагаан гэж үзээд ухарна. Зурагдсан хэсэг хараас цайвар боловч жинхэнэ цагаан
хүрээнээс хамаагүй бараан — тэднийг ялгахын тулд цагаанаа хэмжих ёстой.

**Нэг удаа хийнэ** (BT-ээр `C`, эсвэл D12-г **1.5 сек дарж байх**):

1. Мэдрэгчээ **цагаан хүрээн дээр** тавь → D12 дар.
2. Утга EEPROM-д хадгалагдана — тэжээл унтраасан ч үлдэнэ.
3. Роботоо хар дээр тавиад хэвийн эхлүүл.

Тулаан болгонд хараа дахин хэмжиж, босгыг **цагаан ба хар хоёрын хооронд**
тавина (`CAL_K`). Ингэснээр батарей суух, гэрэл өөрчлөгдөхөд автоматаар дасна.

```
босго = цагаан + (хар − цагаан) × CAL_K
```

| `CAL_K` | Үр дүн |
|---|---|
| 0.30 (анхны) | цагаан 200 / хар 800 → босго 380. Зурагдсан хэсэг ~500 → **үл тоох** |
| ↓ 0.22 | бүр хатуу — зөвхөн маш тод цагаан |
| ↑ 0.45 | зөөлөн — хүрээгээ алдаж байвал |

Калибровк хийгээгүй бол `WHITE_FACTOR` (0.45) ашиглан зөвхөн хараас таамаглах
нөөц арга руу шилжинэ — ажиллана гэхдээ найдвар нь бага.

### Бусад хамгаалалт

1. **`LINE_CONFIRM = 7`** — 7 дараалсан цагаан уншилт (≈4.9 мс) шаардана.
   Богино толбо шүүгдэнэ. Хэт их мэдэрвэл ↑ (9, 11), хүрээгээ алдвал ↓.
2. **Зугтах хурд ≥ дайрах хурд.** `SPD_BACK`/`SPD_ESC_TURN` нь `SPD_ATTACK`-тай
   тэнцүү. Ухралт нь түлхэлтээс удаан бол робот өөрийн импульсээрээ гарна.
3. **`reverseUntilClear()`.** Тогтмол хугацаагаар биш, хоёр QTR цэвэр хар унших
   хүртэл (`BACK_CLEAR_MS` баталгаажуулалттай) ухарна. `BACK_MAX_MS` нь ард
   талын ирмэгээс хамгаална.

## Хурд

| Тогтмол | Утга |
|---|---|
| `SPEED_SCALE` | 0.60 — бүх хурдны ерөнхий коэффициент |
| `PWM_MAX` | **100** — хатуу дээд хязгаар. Хурдыг бүхэлд нь өсгөх бол ЭНИЙГ өсгө |
| `SPD_ATTACK` / `SPD_CHARGE` | 200 |
| `SPD_BACK` / `SPD_ESC_TURN` | 200 (дайралтаас бага байж болохгүй) |
| `SPD_CURVE` / `SPD_SPIN` / `SPD_SEARCH` | 150 / 140 / 135 |
| `PWM_MIN` | 55 — үүнээс доош мотор эргэхгүй |

`PWM_MAX = 100` тул 167-оос дээш бүх утга ижил үр дүн өгнө
(`200 × 0.60 = 120 → 100`).

## Тохируулгын дараалал

1. **Цагааны калибровк хий** — BT `C` эсвэл D12-г 1.5 сек дар. Нэг л удаа.
2. BT-ээр `D` дарж QTR утгыг хар. Роботоо зурагдсан хэсэг ба жинхэнэ хүрээ
   дээгүүр удаанаар өнгөрүүлж, `thr` нь тэр хоёрын хооронд байгаа эсэхийг шалга.
   Зурагдсан хэсгийг мэдэрвэл `CAL_K` ↓, хүрээгээ алдвал `CAL_K` ↑.
3. `BACK_MAX_MS`, `TURN_90_MS`, `TURN_180_MS`-ийг талбай дээр туршиж тааруул.
4. Нээлтийн тактикуудыг `OPEN_TURN_MS` / `OPEN_DASH_MS` / `OPEN_BACK_MS`-ээр тааруул.

## Анхаар

Ард нь лайн мэдрэгч байхгүй тул `BACK_MAX_MS` хэт урт байвал ард талаараа
хүрээнээс гарч болзошгүй. Ард нь QTR нэмбэл найдвартай байдал мэдэгдэхүйц
сайжирна.
